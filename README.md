# portfolio-starter

A one-page personal website you can have live in about ten minutes. Plain HTML and CSS: no installs, no build step.

Made for **Build Your Corner of the Internet** (Notion × CSUS × Douze à Deux, McGill, November 2026).

**Step-by-step guide with screenshots:** https://roy-elia.github.io/corner-of-the-internet/

## Get your own copy live

1. Click **Use this template → Create a new repository**.
2. Name it `your-username.github.io` (your site lives at `https://your-username.github.io`), or any name (it lives at `https://your-username.github.io/that-name/`). Keep it **Public**.
3. In your new repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `(root)` → Save**.
4. Wait about a minute, refresh the Pages settings, and click **Visit site**.

## Make it yours

Everything to change is marked with ✏️ in the files.

| File | What to change |
| --- | --- |
| `index.html` | Your name, intro, links, projects, experience, the "Right now" list |
| `style.css` | Colours and fonts (the variables at the top) |
| `assets/me.svg` | Replace with your photo, e.g. `assets/me.jpg`, and update the `src` in `index.html` |

Edit right on GitHub (press `.` on your repo to open the web editor) or clone it and use any editor. Every commit to `main` redeploys the site.

Dark mode follows the visitor's system setting automatically.
